# AIU-interview
基于本地大模型与YOLO的AI视觉哨兵应用。

## 📁 工程结构
- backend/: 后端API服务（FastAPI）
- frontend/: 前端UI界面（HTML/JS）
- docs/: 工程日志与文档

## 🚀 快速启动命令
1. 安装依赖：`cd backend && pip install -r requirements.txt`
2. 启动后端：`uvicorn main:app --reload`
3. 打开前端：双击 `frontend/index.html`

## 🎨 创意作品说明
本项目实现了一个 **“AI视觉哨兵”**。
- **创意点**：将任务一的大模型（大脑）与任务二的YOLO（眼睛）结合，让AI不仅能识别画面，还能用自然语言向用户进行安防汇报。
- **应用场景**：家用监控、无人值守安防、智能看护等。
