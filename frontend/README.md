# Frontend 模块 - 前端交互界面

本模块负责 UI 组织与数据订阅，通过 Fetch API 与后端接口通信，实现前后端解耦。

## 📂 文件说明
- `index.html`: 主页面，包含两个核心交互模块：
  1. **智能体对话**：输入文本，通过 `GET /chat` 接口获取大模型回复。
  2. **AI 视觉哨兵**：上传图片，通过 `POST /detect_and_report` 接口完成 YOLO 检测，并接收大模型的自然语言汇报。

## 🚀 使用方式
1. 确保后端服务已启动（`cd backend && uvicorn main:app --reload`）。
2. 直接用浏览器打开 `index.html` 即可使用。

## 💡 设计思路
前端只负责 UI 组织和数据展示，不包含任何模型推理逻辑。所有 AI 能力都通过 HTTP 请求调用后端 API 实现，做到了**前后端高度解耦**。
